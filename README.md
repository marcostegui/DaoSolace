# DaoSolace

Turns fragmented cryptocurrency data into actionable insights for analysts and researchers working with decentralized finance platforms.

DaoSolace is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DaoSolace.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure DaoSolace, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
